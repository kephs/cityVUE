# Packaged fictional Organization fixture

`example-organization.png` is a generic 96×96 raster E mark created from fixed geometric shapes for F054 development/testing. It is intentionally public, contains no tenant identity or private information, and has no embedded EXIF/GPS metadata. It is not the Reqro product logo or a client logo. Only the fixed `example-organization` configuration key maps to this asset.

Production Organization-logo upload/storage remains deferred. Do not accept arbitrary asset URLs, filesystem paths or uploaded SVG through this registry. Canonical Reqro assets are separate under `../reqro/` and must remain unchanged.
