## Approved design

The user explicitly approved self-reported service-participation area, not residence; the question is **Which area do you associate with this service request? (Optional)**. Include Prefer not to say and explain that the answer neither changes nor derives from Service Location. Collection is voluntary, request-level and explicit. No coordinates, geometry, identity inference or permanent Requester profile. Anonymous PUBLIC requests may provide an area without Contact or identity linkage. INTERNAL collection is prohibited.

The dedicated `analytics.service_participation.read` permission has zero default grants and is excluded from broad bundles. Analytics additionally requires PUBLIC read and current Department/Division scope, before PostgreSQL aggregation. Permission alone never expands visibility. Development denial must precede a narrow explicit UAT grant.

Organization-scoped opaque area IDs, name, active state and deterministic order form the minimal catalog. Historical references survive rename/deactivation; analytics uses current labels. New selections require an active area. Request state is PROVIDED with area, DECLINED without area, or NOT_COLLECTED without area. Omitted input means not collected (including optional skips, unavailable collection and legacy callers); clients cannot explicitly submit NOT_COLLECTED. Existing requests receive only the truthful NOT_COLLECTED default. Request geography is immutable after creation. Finalized evidence retries return their original receipt before current area validation.

Analytics counts PUBLIC requests, never people. Server configuration defaults to threshold 5 and rejects values below 5. Positive counts below threshold become suppressed/null before disclosure; zero is shown as zero. Apply uniformly to areas, declined and not-collected. No grand totals, percentages, cross-tabs, drill-down or exports. Required inclusive UTC date-only ranges span 28–366 days, with no future dates; preview defaults to the last 365 days including today. Limited dimensions and minimum duration mitigate but do not eliminate repeated-query differencing. Safe required audit contains actor/Organization/period/threshold/correlation/time only; no counts or individual geography.

Individual geography stays out of staff detail/list, Contact, history, tracking, communication, attachment and search projections. No routing/assignment/eligibility effect. Existing geospatial and MapLibre resources remain Service Location tools only. Production area governance, analytics access/privacy/retention approval and administration remain deferred.
