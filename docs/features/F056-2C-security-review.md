## Threats and residual risks

| Threat                                                                       | Mitigation / evidence                                                                                                             | Residual boundary                                                                                            |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Forged, duplicate or foreign question/version/Organization option            | Server membership validation; captured-version and composite foreign keys; selected-option primary key; strict representation     | Semantic keys are scoped by owning question/version, not globally authoritative                              |
| Selection mutation, late append, partial response or destructive cascade     | Immutable parent/children, no cascade; deferred exact-count constraints, including concurrent append tests                        | A privileged database owner can deliberately disable controls; production role governance remains required   |
| Invalid Date or timezone drift                                               | Strict component/leap parsing, DATE bounds, canonical SQL text projection, shared formatter with no instant conversion            | Browser date-picker appearance varies; English wording is current scope                                      |
| Forged Information answer                                                    | Domain rejects every entry; Answer identity/type trigger and CHECK exclude Information                                            | Information remains eligible catalog schema, not secret staff-only content                                   |
| Information/option-label XSS                                                 | React text nodes and semantic lists; no HTML/Markdown evaluation                                                                  | Future rendering changes must preserve escaping                                                              |
| Required bypass, stale schema, API bypass                                    | Shared authoritative validator and current Issue/version lock; required/hidden/membership checks                                  | UI validation alone never grants acceptance                                                                  |
| Answer/legacy/public/search/analytics leakage                                | Parent + answers.read; dedicated audited no-store path; ordinary detail excludes answers; projection allowlists; no new consumers | Already disclosed authorized browser content cannot be retroactively erased; no automatic PII classification |
| Contact/Requester/location/participation inference or answer-driven workflow | Separate fields/services and explicit mutation inputs; no answer mapping                                                          | Admins must still author appropriate questions; content can contain incidental PII                           |
| Logging leakage                                                              | Fixed/sanitized errors, body/query/response exclusions, new-type marker assertions and manual live log gate                       | Manual confirmation is recorded only after firsthand user inspection                                         |
| External Redirect question leakage                                           | Catalog suppresses entire schema and creation rechecks handling; live handoff and regression tests                                | Existing F032 domain/DNS trust limitations are unchanged                                                     |
| Partial request/contact/location/assignment/Activity/evidence                | Bulk typed writes inside established request transaction; injected selection/date failure and finalized retry tests               | Provider/distributed atomicity beyond existing architecture is not introduced                                |
| Migration history loss                                                       | Preflight reserved-type inspection; original-value hashes; disposable apply/rollback/reapply; retained-data rollback guard        | Production application/rollback requires its separately authorized operational process                       |
